Copper Bay Labs studio dashboard — live from the GitHub API in your browser. No server, no build, hosted free on GitHub Pages. Shows what's on GitHub: last commit, unmerged branches (with commit counts), open PRs, CI status, the owner-action brief, the latest overseer run, shipped products, and the forge idea pipeline. It can't see your laptop's uncommitted work — run overseer.bat locally for that. Add a GitHub token (read-only; stored only in this browser) to unlock private repos, PRs/CI, and a 5000/hr rate limit. Auto-refreshes (5 min with a token, 20 min without).
